# Documentation image attribution

Captured from the current local production source on October 21, 2026, in isolated browser profiles without browser chrome, account dashboards or personal data. The captures use real public Wikimedia summaries and corresponding Commons photographs in a small documentation fixture, rather than asserting a particular random opening sequence. Saved articles and the “Small wonders” collection are synthetic demonstration data. The animations use actual keyboard and touch events with the reader. Frame-by-frame capture advances the app clock at 60 samples per second; MP4 files preserve 60 fps and inline GIFs use 50 fps. These are deterministic UI demonstrations, not a measurement of device frame rates.

- Article text: [Glaucus atlanticus](https://en.wikipedia.org/wiki/Glaucus_atlanticus), [STEVE](https://en.wikipedia.org/wiki/STEVE), and [Socotra](https://en.wikivoyage.org/wiki/Socotra). Text is [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); each article’s history identifies its contributors.
- Blue dragon photograph: [Sylke Rohrlach, CC BY-SA 2.0](https://commons.wikimedia.org/wiki/File:Blue_dragon-glaucus_atlanticus_(8599051974).jpg).
- STEVE photograph: [Krista Trinder, via NASA Goddard, CC0 as listed on Commons](https://commons.wikimedia.org/wiki/File:The_Aurora_Named_STEVE_(26938621338).jpg).
- Socotra photograph: [Boris Khvostichenko, CC BY-SA 4.0](https://commons.wikimedia.org/wiki/File:Socotra_dragon_tree.JPG).

Images are resized and positioned by the actual reader layout. The documentation photos are not AI-generated. Screenshots and GIFs contain no EXIF, workstation paths or embedded capture logs. The WikiScroll name and logo retain their separate branding terms in the main README.
